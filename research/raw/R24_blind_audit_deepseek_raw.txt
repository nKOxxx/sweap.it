## DATA DICTIONARY (v3 rows, schema:3)

- uid: ts|session|model (unique key; ts = unix seconds of window close)
- tick_s: sampler tick interval (60)
- idle_s: seconds since previous observed call on the same (session, model)
- d_calls, d_input, d_cache_read, d_cache_write, d_output: per-window token
  deltas per (session, model)
- merged: true = multiple calls share this window; per-call split
  unavailable at sampler grain
- write_field_trust: "dead" = the d_cache_write field is known unreliable
  (provider writes off-ledger); do NOT treat 0 as "no writes happened"
- provider: zai (paid lane) vs others; PER-LANE LAW: never blend paid and
  free lanes in one hit-rate number
- row_kind: per-window deltas
- v2 rows (no schema field): same idea, older field layout (ts-only key,
  gap_s instead of tick_s/idle_s). Treat as historical; the v2 write column
  is likewise dead.

Compaction events: {ts, session, model, kind (compaction/manual/...),
ctx_before, ctx_after, source, note}. A compaction means the provider's
prompt prefix was replaced; the next call on that lane re-bills the prefix
at full input price.

## COMPUTE (show formula + number for each)

A1. Per-model lifetime table on v3 rows only: calls, input tokens,

A3. Break candidates on v3: a window whose idle_s is large (>= 1800s) OR
    within 120s after a compaction event for the same (session, model).

A4. For each compaction event with a following same-lane call within 120s:
    the next window's hit rate (this is the compaction-cost receipt).
A5. The single worst full-price re-bill window on v3 (largest d_input) and

A6. Sanity: total v3 rows, total v2 rows, distinct (session, model) lanes,
