# R35: research paper - working outline

Status: SCOPING (2026-10-20). Nothing here publishes without the founder's go.
Candidate title (working, honest): "Dead Weight in AI Agent Memory Stores:
A Cross-Vendor Census, a Reversible Diet, and a Regrowth Law"

## Thesis (one line)

Production AI agents carry measurable dead weight in their local memory
stores (duplicate reasoning twins, resting tool exhaust), this weight has a
computable carrying charge at every major vendor's published prices, it can
be removed reversibly with zero information loss, and it regrows at a
measurable daily rate: therefore memory hygiene is a recurring maintenance
discipline, not a one-time cleanup.

## Section map (each section re-uses filed studies; nothing new invented)

1. Introduction: the store plane (R13) and why nobody measures it.
2. Background: how Hermes / Claude Code / Codex persist agent memory
   (R23 adapter work, R31, R32 census method).
3. Measurement method: weigh-in classifier, twin detection, byte ledgers;
   the verification protocol itself (blind worker briefs, needle gating,
   hub recount: R14, R16, R24; contamination law as a named threat model).
4. Census results:
   - Hermes: 90.69% dead tool output in stored transcripts (n=37,813),
     9,469 duplicate blobs, 37.57 MB recovered (R25, R26).
   - Claude Code: dual envelopes, no byte-identical dupes, 5-15%
     recoverable band (estimate) (R31).
   - Codex: 24% content density, 390 MB program, encrypted reasoning (R32).
   - Cross-model twin-column structure (R25a).
5. The regrowth law: ~431 exhaust rows/day post-clean; Class A twins
   regrow even when Class B holds (R25 + live daily scale since 2026-10-17).
6. The carrying charge: $0.49 / $2.70 / $0.24 / $0.15-0.29 per 1M junk
   tokens per lapse (official lists, retrieval-stamped, R28 + R33);
   $8.09 per lapse on the measured reference store.
7. The diet: reversible removal with hash-verified quarantine, restore
   drill under schema change (R26, R27), 18-point security audit (R29).
8. Threats to validity: single reference host for the deep numbers,
   vendor-side schema drift, worker-verification limits (honest section,
   already half-written across R18/R20/R24 errata).
9. Reproduction: the stranger-runnable receipt (repro_receipt.py, CI-run)
   and the public receipt board (live tester receipts become Reproduction
   section evidence as they land).
