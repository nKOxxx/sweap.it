## Section map

1. **Introduction** - the topic: production agents keep local memory
   stores; the store plane exists and nobody measures it (R13).
2. **The issue** - dead weight: duplicate reasoning twins + resting tool
   exhaust; why it bills (memory lapse = 0.0% cache hit = full-price
   re-read). Ends on the gap no prior work fills.
3. **Related work** (added block, ~half page) - in-path compressors and
   context managers shrink traffic in flight; agent-memory hygiene at rest
   is the unclaimed lane. Honest nods: caveman (talk less), the vendor
   context docs. What none of them do: census the store, price the weight,
   prove reversible removal.
4. **How we measured it** (founder beat 3, in detail) - the weigh-in
   classifier, twin detection, byte ledgers (R23, R25, R26); the three
   stores and their adapters (R31 Hermes, R31b Claude Code, R32 Codex);
   the verification protocol as a named method: blind worker briefs,
   needle gating, hub recount, contamination law (R14, R16, R24).
5. **Findings** (founder beat 4) -
   a. Census table: 90.69% dead (Hermes, n=37,813) / 4.8-14.8% band
      (Claude Code) / 9.5-14.4% (Codex); cross-model twin columns (R25a).
   b. Regrowth law: ~431 rows/day, live scale since 2026-10-17 (R25).
   c. Carrying charge: charge = input price - cache-read price per 1M
      junk tokens. Five vendors: glm-4.6 $0.49, Claude Sonnet-class
      $2.70, Codex symbolic (no public list), **MiniMax and DeepSeek from
      R36** (official lists, retrieval-stamped). $8.09 per lapse on the
      measured store. Savings-if-dieted framing: we run free lanes; the
      table prices what a paying runner would save.
   d. The diet: reversible removal, hash-verified quarantine, restore
      drill under schema change (R26, R27), 18-point security audit (R29).
6. **Limitations** (added block, honest) - single reference host for the
   deep numbers; B is a band, not a point; C row symbolic; worker
   verification limits (R18, R20, R24 errata folded here).
7. **Reproduction** - repro_receipt.py (CI-run, ends RECEIPT-REPRO-OK);
   the public receipt board; outside receipts become evidence as they land.
8. **Conclusion** (founder beat 5) - memory hygiene is a recurring
   maintenance discipline with a computable price, not a one-time cleanup.
